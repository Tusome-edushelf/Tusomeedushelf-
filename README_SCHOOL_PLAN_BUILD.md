# Tusome EduShelf — School Plan Build

This build expands the existing School Plan without replacing the existing Render architecture.

## Included
- School account access and workspace selection
- School Executive Overview with live counts for teachers, learners, classes, attendance, exams, assignments, fees billed and parent links
- Existing People / Classes / Parent links management
- Existing academic setup, subjects, terms and teacher allocations
- Existing assignments, submissions and gradebook
- Existing attendance and calendar
- Existing timetable and clash checks
- Existing fees and payment records
- Existing exams, marks and report-card workflow
- Existing school announcements and messaging
- Existing approved digital learning resources
- Existing Tusome school AI support

## Reference boundary
The structure is informed by publicly documented school-management capabilities such as academic records, attendance, parent access, communication, fee tracking and reporting. It does not copy Zeraki proprietary code, branding or exact UI.

## Deployment
Deploy `index.html`, `server.mjs`, and `tusome-ai.html` together and restart the Render Node service.
