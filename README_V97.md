# Tusome EduShelf v97 – Visible Learner Reset

This update keeps the v96 functionality and moves the **Clear Learner Data & Accounts** action out of the Bulk Registration section and places it directly above the **Registered Learners** list.

The reset remains protected by the exact confirmation text:

`RESET LEARNERS`

It preserves the school, classes, subjects and staff while clearing learner data and school-linked parent accounts according to the existing v96 reset logic.

No learner registration, parent credential, DOB, class, subject, or staff business rules were changed.
