# Tusome EduShelf v32 — Learner Quiz & Practice Mode

Adds a learner-only practice area with subject/topic selection, multiple-choice questions, instant checking, explanations, score/progress feedback, retry, and local best-score tracking. Existing v31 reader, notes, highlights, bookmarks, study planner, AI, dashboards, notifications, accessibility, payments and B2C code are preserved.

Practice is a self-checking learning aid and not a substitute for teacher assessment. Dynamic feedback uses accessible status patterns.
