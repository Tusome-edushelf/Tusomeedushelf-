# Tusome EduShelf v124 – Teacher Mark Sheet Names & Sorting

Changes from v123:
- Teacher online exam mark sheet displays learner full names and admission numbers instead of learner emails.
- Learners are sorted alphabetically by name by default.
- Teacher can switch ordering to admission number.
- Direct in-system mark entry remains the primary workflow.
- Learner email remains an internal identifier only for secure server-side saving.
- Teacher mark saving follows the displayed sorted order safely.
- Server roster now returns full name and admission number from learner profile/user records.
- Existing teacher assignment/security and maximum-mark validation preserved.
- No database reset, GitHub changes, or deployment.
