# Tusome EduShelf — Home AI Onboarding + Learner Shelf Theme v13

This release keeps the Home AI onboarding assistant and adds the new homepage visual theme requested for Tusome EduShelf.

## Homepage changes
- Adds the generated library scene showing two learners of different genders choosing books from a shelf.
- Uses the scene as the left-side visual of the Home hero section.
- Keeps the interactive right-side welcome area with Get Started and Ask Tusome AI actions.
- Keeps the public Home AI onboarding assistant available without login.
- Keeps the existing learner, teacher, admin, parent/guardian and role-specific AI functionality unchanged.
- Uses a responsive layout so the visual and welcome content stack cleanly on smaller screens.

## Deployment
Replace the current project with this ZIP on Render and redeploy. Existing environment variables remain unchanged.
