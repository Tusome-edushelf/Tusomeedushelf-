TusomeEduShelf v125 - Teacher X/Y Exam Status

Teacher exam marking is direct in the system; CSV exam-mark entry is removed from the UI.
Teachers can mark each learner as:
- Present: enter numeric marks.
- X - Did not do/sit exam: no numeric marks.
- Y - Exam irregularity: no numeric marks.

Learners are displayed by name and admission number, with alphabetical/admission sorting.
Maximum marks are set by the teacher before saving.
Database adds mark_status with safe migration.
No GitHub changes or deployment are performed by this package.
