# Tusome EduShelf v77 — Bulk Learner Registration Dashboard

This build makes Bulk Learner Registration a first-class, visible School Admin feature.

Visible entry points:
- School Management Centre → Bulk Learner Registration module
- School Management Centre → Quick Actions → Bulk Register Learners
- Existing learner registration area → Bulk Register Learners

The existing CSV upload, preview, validation, registration endpoint, and credential report remain included.

Deploy `index.html`, `server.mjs`, and `package.json` together, then trigger a fresh Render deploy.
Verify `/api/version` reports `v77-bulk-registration-dashboard`.
