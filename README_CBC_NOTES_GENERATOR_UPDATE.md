Tusome EduShelf — Detailed CBC Notes Generator Update

This update preserves the existing EduShelf structure and standalone Tusome AI page.

Notes Generator changes:
- Added selectable Grade, Learning Area, Strand and Sub-strand fields.
- Added cascading Strand -> Sub-strand selection.
- Added built-in CBC structure for selected Junior School Mathematics and Grade 7 Integrated Science combinations, with a safe custom/verification option for other combinations.
- Notes generation now produces substantially more detailed original study/teacher notes.
- Output is structured around CBC-style elements: learning intention, original learning outcomes, vocabulary, detailed concepts, worked examples, applications, activities, inquiry questions, competencies, values/PCIs where relevant, misconceptions, assessment tasks with answer guide, revision summary, and verification/references.
- The generator does not reproduce or host KICD curriculum documents, textbooks, publisher materials or KNEC papers.
- Exact current curriculum wording should be verified against the official KICD curriculum designs.

Official reference:
